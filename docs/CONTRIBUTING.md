# 投稿与编辑指南

打开[投稿表单](https://schemer.online/submit)，填写**你的称呼（可用昵称）**和**事件或更正内容**。详情页的“补充或更正条目”会自动带入条目名称和页面地址。

请说明事件经过和时间，并附上官方文件、公开裁判文书或新闻报道等可核查链接。更正请求请指出条目地址、具体错误与依据。以事实为主，避免对当事人作法律或道德定性，不提交无法验证的指控，也不要在表单中填写身份证号、住址等敏感资料。

## 提交与查询

提交前浏览器会生成私密回执，只有服务端确认入库后才显示“投稿已收到”。请保存回执，在投稿页“查询处理进度”中查看状态和处理说明。无需邮箱、电话或账号，系统不会发邮件通知；持有回执的人都能查看结果，请勿公开分享。

若连接中断，可使用同一回执查询，或在原表单重试。同一回执与相同内容不会重复创建投稿。不要为同一件事反复点击“开始新投稿”。回执只在当前浏览器会话中暂存，遗失后无法通过称呼找回。

投稿原文和称呼仅供维护者后台查看，不会自动公开。处理说明和已发布档案链接仅通过回执查询返回。旧版表单没有发放回执，历史投稿无法通过新查询功能找回。

## 审核与收录

“待查看”表示已接收；“核查中”表示正在审核；“待整理发布”表示进入编辑流程，仍未公开；“已收录 / 更新”提供实际公开档案的链接。更正、下架等请求也可以标记为“已处理”；不收录时会注明原因。提交不保证收录，维护者仍需核查信源。

## 直接编辑档案

有仓库写权限的贡献者通过 Pull Request 修改 `src/content/`。提交前运行 `npm run validate` 检查内容。编辑完成、校验通过并部署后，管理员再将对应投稿标记为“已收录 / 更新”，关联真实档案路径。状态更新本身不会创建、编辑或部署内容页面。
