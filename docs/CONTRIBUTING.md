# 投稿与编辑指南

感谢你愿意为恶人百科补充内容。投稿入口只收集两项：**姓名**和**事件**。

## 提交投稿

打开[投稿表单](https://schemer.online/submit)，填写姓名和事件内容后提交。详情页的“补充或更正条目”入口会自动把当前条目带入事件栏，仍只需填写这两项。

投稿记录保存在维护者密码保护的后台，供人工审核。表单不会要求邮箱、电话或账号；请勿填写身份证号、住址等敏感资料。

## 投稿内容要求

- 以事实为主，避免对当事人作法律或道德定性。
- 尽可能说明事件经过和时间，并提供官方文件、公开裁判文书或主流媒体报道等可核查材料。
- 不提交未成年人案件、个人隐私或无法验证的指控。
- 重复、无公共讨论价值或缺少可核查依据的投稿可能不会被收录。

维护者会审核投稿，再决定是否整理成公开档案。提交不代表内容会自动发布。

## 直接编辑档案

有仓库写权限的贡献者可以通过 Pull Request 修改 `src/content/` 中的档案。提交前运行 `npm run validate` 检查内容。
