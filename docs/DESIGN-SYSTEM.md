# 恶人百科 · 深色档案设计系统

更新日期：2026-10-23。适用于首页、档案索引与详情、搜索、收藏、投稿及管理后台。

本规范依据当前源码编写。基础变量与页面布局见 [global.css](../src/styles/global.css)，首页结构见 [index.astro](../src/pages/index.astro)，组件专属布局与状态保留在各组件中，Tailwind 映射见 [tailwind.config.mjs](../tailwind.config.mjs)。

## 视觉方向与品牌

视觉结构借鉴 JUNNI 的深色瓦片、大尺度文字、极简菜单与鲜明强调色。网站品牌、标题、文案、档案和导航均属于「恶人百科」；页面使用「THE PUBLIC ARCHIVE」与「让事实，留下来。」表达自身定位，不使用 JUNNI 商标或将其品牌内容作为本站内容。

页面以接近黑色的背景、分层灰色表面和暖白文字承载公共记录。荧光黄绿用于主要行动、当前选中、文字链接、焦点和首页宣言。低饱和主题配图附「示意配图」说明；事实、主张、待核实事项和信源继续分别呈现。

首屏使用真实 HTML 文案与链接，并在支持动态效果时增强为 CSS 3D 正反面切片。每块瓦片包含按空间位置裁切的正面与背面 HTML，标题不是一张图片。视觉切片层设置 `aria-hidden` 与 `inert`，不拦截点击；正文中的原始文案和链接负责可访问性与导航，不让切片副本重复进入阅读或焦点顺序。

| --- | --- |

## 字体与文字层级

## 首页结构

### 首屏 3D 翻转舞台

首页品牌首屏 `.archive-portal` 与荧光宣言 `.archive-manifesto` 共处于 `.flip-story > .flip-stage` 内。增强模式下，桌面与手机的舞台和外层均为 `100svh`，使用普通文档定位。停留在舞台顶部时，一次向下滚轮、竖向触摸、PageDown 或空格触发整组约1秒的翻转，从深色品牌正面切到荧光宣言背面。消费触发此次切换的手势及其惯性后，下一次下滚按浏览器原生行为浏览后续内容；返回舞台顶部再上滚可翻回品牌面。当前实现没有长距离 sticky 占位，也不将页面滚动距离连续映射成翻转角度。

桌面为 6 列 × 6 行共 36 块切片，600px 及以下为 3 列 × 6 行共 18 块。每块具有独立正反面，正面保留3px缝隙与9px圆角；`preserve-3d` 与隐藏背面保留真实翻转关系。舞台透视距离为桌面1400px、手机900px；切片层上下各留8px，左右分别为桌面10px、手机6px。

每块背面按自身翻转阶段 `phase` 向四周延展，最大各1.5px，同时将圆角从9px收至0；内部文案偏移同步补偿。这个延展在背面悬停运动时也保留，用于消除常驻粗黑网格及缝隙造成的文字缺笔。背面完成翻转并静止、且没有指针扰动时，再显示唯一原始宣言文字层、隐藏背面切片中的文字副本。重新发生翻转或指针动作时回到切片显示，文字继续随各自瓦片运动。

未增强时，品牌首屏与宣言按原始文档顺序上下排列。此时品牌首屏保持 `100svh`、桌面最小高度 660px；手机最小高度 620px。静态网格仍为桌面 6×6、手机 3×6；手机品牌字为 `19vw`，副标为 28px。暂停、减少动态效果、视口高度低于 560px、不支持所需 CSS 或禁用 JavaScript 时使用这一降级布局。

「SCROLL DOWN」文字环围绕黄绿箭头旋转，整体保留跳转到 `#archive` 的原生链接与中文可访问名称。增强模式中的正常点击定位到舞台顶部并触发背面翻转，完成后把焦点移到宣言标题；降级模式使用原生锚点导航。底部同时保留「探索档案」入口、简短定位与竖排版权信息。

### 荧光宣言与档案栏目

黄绿底的 `.archive-manifesto` 在增强模式下是舞台背面，降级模式下位于品牌首屏之后。它包含描边英文 `FACTS × CONTEXT`、中文主张、进入事件档案的链接及事件、人物、机构、信源计数。数字来自当前已发布内容；桌面统计为四列，手机为两列。增强模式为完整背面内容预留上下空间，并将进入档案的链接放在舞台底部。

后续栏目按以下顺序展开：

1. **RECORDS / 事件档案**：最多四条最近更新事件；依视口使用4、3、2列紧凑网格，手机为单列横排卡片；全部档案入口带更新时间排序参数。
2. **INDEX / 人物与机构**：中文引导语、人物与机构卡片，以及各自完整索引入口。
3. **TOPICS / 话题索引**：编号、大字话题名称和箭头组成的纵向目录。
4. **收录原则**：严格信源、中立记录、开放更正三块深色入口瓦片；手机依次纵向排列。

栏目标题使用大尺度英文和较小中文说明。桌面主栏目最大宽度 1680px，常用内边距为上下 100px、左右 60px；手机改为上下 64px、左右 20px。

## 页头、菜单与页脚

[Header.astro](../src/components/Header.astro) 在首页使用固定页头，首屏品牌由主标题承担；内部页面显示「恶人百科」与英文副标。右侧保留 SEARCH 和 MENU，使用48px圆形图标触点。舞台处于页头下方的整个翻转过程保持透明，无全宽背景、阴影或模糊遮罩；黑面按钮为暖白色，右上区域翻到荧光面后按钮、图标、边框与焦点轮廓切为黑色。由 `flip-stage-visible` 控制舞台范围、`flip-on-green` 控制按钮配色，各组件自行处理样式。离开舞台后才允许半透明深色导航底；内部页面向下滚动时可收起页头，页头内获得键盘焦点时恢复显示。

MENU 打开全屏原生 `<dialog>`：左侧是带编号、英文小标题、中文大标题和箭头的主要导航，右侧是辅助页面、档案导航与动画开关。当前页面用黄绿文字及 `aria-current="page"` 标识。700px 以下改为纵向结构，SEARCH 隐藏文字但保留可访问名称与图标按钮。

[Footer.astro](../src/components/Footer.astro) 以「让记录持续发生。」的大字投稿入口收尾，辅以黄绿圆形箭头、RSS、页脚导航、版权和中立记录声明。回到顶部是独立的 48px 圆形按钮。

事件卡网格统一由 `.records-grid` 与 `.event-card-grid` 控制：首页、事件列表、话题页及事件收藏在1200px及以上为4列，900–1199px为3列，600–899px为2列，599px及以下为单列。桌面网格间距16px，手机14px。事件卡本体由 [EventCard.astro](../src/components/EventCard.astro) 管理密度，父网格只决定列数与间距。

桌面事件卡的配图外框仅上方和两侧留7px，正文内边距为11px 14px 13px；类别和状态、日期、标题、两行摘要、节点与信源计数依次排列。手机改为84px图片列加弹性正文列，卡片内边距12px、列间距12px；359px及以下缩为68px图片列、10px内边距与列间距。标题完整换行，摘要最多两行；图片中的装饰箭头在手机隐藏。

整张档案卡是一个链接，卡内箭头提示不作为独立按钮。涉及主体链接与关联档案链接分别渲染，不嵌套 `<a>`。卡片摘要可截断，详情正文和事实概览不以卡片截断方式隐藏。

时间线用细竖线、黄绿节点、日期与明确的信息性质标签组织内容；信源链接使用强调色或暖白文字。概览、归档提示、分享和引用区使用深色层级，保留各自标题、说明及展开行为。

## 控件、表单与结果反馈

通用 `.pill-button`、筛选、排序、收藏、分享、引用复制与引用展开操作的最小高度为44px。页头菜单、搜索和关闭操作使用48px触点；投稿主输入与主提交操作为48px。正文内的 `EntityLink` 最小高度为36px，按正文关联链接排版；卡片内的箭头是装饰提示，不额外形成独立按钮。

| 状态 | 当前视觉与语义 |
| --- | --- |
| 默认 | 深色或透明底、暖白文字、灰色边框 |
| 悬停 | 黄绿文字或边框；主按钮可使用黄绿底、深色字 |
| 当前 / 选中 | 黄绿底、深色字；筛选和排序保留URL状态，收藏同步 `aria-pressed` |
| 键盘焦点 | 2px 黄绿轮廓，常用外偏移4–5px |
| 输入焦点 | 黄绿边线与轮廓；搜索采用容器下边线反馈，不重复叠加输入轮廓 |
| 禁用 / 提交中 | 禁用相关动作并显示处理中说明；表单按钮降低透明度 |
| 成功 | 确认完成后显示文字反馈，使用 `role="status"` 或 `aria-live` |
| 错误 | 暖红提示与明确文字，保留可重试路径 |

表单使用 `--page` 输入底色、`--line` 边框、暖白输入文字、浅灰占位符和黄绿光标；原生控件使用深色配色。回执与审核结果显示在较亮一层的深灰区域，状态与处理说明分开展示。管理后台的动态内容沿用同一套暗色面板、输入和按钮样式。

复制操作检查实际剪贴板结果；失败时显示可选中的只读文字。分享可以使用系统分享、复制链接或邮件。收藏写入失败时提供文字反馈；失效收藏有独立说明和清理入口。

## 搜索与对话框

搜索是深灰原生对话框，桌面最大宽度860px，8px圆角；手机宽度为视口减24px。标题、下划线式输入区、可滚动结果区和键盘提示形成连续阅读顺序。结果悬停及当前选择使用黄绿边框、抬高一级的灰色底；命中词使用黄绿底和深色字。

搜索支持 `⌘ / Ctrl K`、上下键、回车与Escape，输入法组合输入不触发结果跳转。输入框、结果列表及选项提供组合框/列表框语义，同步 `aria-activedescendant` 和 `aria-selected`。初始、加载、无匹配与错误状态分别显示；索引请求12秒超时后可原地重试。

图标使用 `/public/icons/` 中的SVG资源。菜单三点使用 `dots.svg`；菜单、页脚与首屏滚动入口复用SVG箭头，不用文本字符模拟操作图标。

菜单、档案导航和搜索使用原生 `<dialog>`。打开时锁定背景滚动，关闭后恢复触发位置；在对话框之间切换时根据是否仍有打开的对话框保留滚动锁。装饰图标使用空 `alt`，纯图标操作具有明确的中文可访问名称。

颜色用于辅助识别工作流和交互，不用于判断当事人。状态始终以文字呈现。

| 已发布 | 黄绿文字与轻微黄绿底色、边框 |

## 动效与暂停

### 手势触发与指针输入

整组翻转由一次场景切换触发，时间线约1000ms，使用 `rotateX` 完成180°正反面切换。列方向60%、行方向40%形成对角错峰；单片翻转由归一化时间线进度计算并使用平滑插值。角度不由滚轮位移持续拖动，触发后会完成整组切换。

舞台顶部的向下滚轮或竖向单指触摸触发正面至背面；此次手势及惯性在舞台内消费，结束后新的下滚手势直接浏览后续页面。回到舞台顶部后向上滚动，或对应方向的触摸，可翻回正面。键盘ArrowDown / PageDown / 空格触发背面，ArrowUp / PageUp / Shift+空格触发正面；输入框、按钮、链接等控件获得焦点、带组合修饰键或打开对话框时不接管这些键。滚轮监听覆盖舞台内的顶部导航区。触摸从首个竖向移动判定，链接、按钮和输入控件不接管；横向滚动与缩放手势不用于场景切换。

支持悬停且具有精细指针的设备上，在整组切换结束后进入一块新瓦片，可触发约1秒的360°单片翻转；邻近瓦片按距离倾斜、轻微抬升并改变阴影。指针停止移动后，邻近倾斜在260ms内归零，当前单片翻转完成后停止请求动画帧。独立的装饰文字圆环跟随指针，悬停画布时隐藏系统光标及圆环中的固定箭头，不替换原始锚点链接。整组滚轮翻转保留圆环位置。触屏不启用这组悬停效果；指针经过链接、按钮或打开对话框时不干扰原操作。背面延展填缝按瓦片 `phase` 保持，悬停时也不恢复切断小字的固定粗黑网格。

滚动文字环自身以28秒一圈旋转。事件卡图片悬停缩放至1.025倍，卡片轻微上移2px，按钮、链接与边框使用短过渡。舞台场景切换由用户主动触发，不自动轮播档案内容。

### 暂停、降级与生命周期

动画开关位于菜单内，保存在当前浏览器的 `archive-motion` 设置中。系统 `prefers-reduced-motion` 始终优先；系统减少动态效果时开关显示“系统已减少动态效果”且不可点击，但保留用户原有偏好，系统恢复后重新使用该偏好。暂停或系统要求减少动态效果时，移除3D增强层，恢复品牌首屏和宣言的上下正文布局；滚动文字环停止，平滑滚动取消。视口高度低于560px、缺少 `preserve-3d` 支持或 JavaScript 不执行时，也保留正常正文和锚点入口。回到顶部采用即时定位。

瓦片只在整组切换、悬停翻转等未完成时持续申请动画帧。舞台离屏、页面隐藏或离开页面后停止持续 RAF；重新可见时依据当前场景状态恢复。切换增强与降级模式时，按当前所在正面、背面或下方内容调整滚动位置，避免展开高度变化把阅读位置丢失。

窗口尺寸变化、字体加载完成及 `pageshow` 会重新计算切片尺寸和偏移。`#archive` 支持直接进入与正常链接点击；主动点击完成后将焦点交给背面标题。浏览器前进后退恢复时依据已恢复滚动位置重建，避免再执行一次初始锚点跳转。非当前面及翻转中的链接从焦点顺序中移除，视觉副本始终不参与辅助技术阅读。

## 打印

打印样式切换为白底、深色文字和灰色边线；隐藏页头、页脚、首屏翻转舞台、荧光宣言及 `.no-print` 操作模块，内容容器取消屏幕留白。正文与信源保留，链接转为深色。进入打印前释放舞台增强并记录滚动位置，退出打印后按当前动效偏好重建，恢复原场景及滚动位置。
