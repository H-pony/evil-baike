# 恶人百科 · Journal 设计规范

更新日期：2026-10-23。适用于公开档案、索引、搜索、投稿和通用控件。

本规范记录当前实现，后续修改以 `src/styles/global.css` 的基础变量与组件规则为主；Tailwind 的颜色与字体映射见 `tailwind.config.mjs`。组件内仅保留该组件专属的布局与状态样式，避免复制第二套全局按钮、颜色或断点。

## 视觉原则

- 保持公共档案刊物的阅读感：浅灰纸面、深蓝正文、细线分区、圆角白色卡片。
- 粉色与浅蓝用于装饰和栏目背景，不表示事实可信度、人物立场或法律结论。
- 状态必须有文字。正文、信源、待核实说明与操作结果优先于装饰。
- 保留现有星形图案、网格底纹与胶囊按钮；新增页面沿用现有组件。

## 颜色

| Token / 映射 | 值 | 用途 |
| --- | --- | --- |
| `--navy` / `--ink-900` / `--archive-seal` | `#0e0d6a` | 主文字、主操作、选中状态、焦点轮廓 |
| `--ink-950` | `#0e0d40` | 深色遮罩基色 |
| `--page` / `--ink-50` / `--archive-paper` | `#f2f3f8` | 页面背景 |
| `--ink-100` / `--archive-aged` | `#e7e9f2` | 次级表面、悬停背景 |
| `--ink-muted` | `#565780` | 次级说明、摘要 |
| `--ink-faded` | `#6f7090` | 元信息、辅助提示 |
| `--line` | `#dde0e7` | 分隔线、默认控件边框 |
| `--pink` | `#ffafcb` | 引文边线、选中文字底色、装饰 |
| 白色 | `#ffffff` | 卡片、按钮、表单表面 |

`--ink-*` 和 `--archive-*` 是空格分隔的 RGB 值，使用 `rgb(var(--ink-900) / .22)` 等写法支持透明度。`--navy` 等变量是完整颜色值，使用 `var(--navy)`。

筛选与排序的选中态统一为深蓝底、白字、深蓝边框。错误、风险等级与状态信息可使用语义色，但不能依赖颜色独自表达含义。

## 字体与层级

| 场景 | 当前规则 |
| --- | --- |
| 中文正文、通用 UI | `Geist, PingFang SC, Microsoft YaHei, sans-serif` |
| 英文眉题、统计数字 | `Montserrat, Geist, sans-serif` |
| 正文 `.prose` | 桌面 16px，600px 以下 15px；行高 1.9 |
| 正文二级 / 三级标题 | 25px / 20px，深蓝；行高 1.5 |
| 按钮 `.pill-button` | 14px / 1.4，字重 700 |
| 元信息 `.meta-stamp` | 12px；次级色；不用于承载主要操作说明 |
| 首页主标题 | 桌面 `clamp(32px, 3.1vw, 52px)`；手机 `clamp(24px, 7.5vw, 30px)`；行高 1.55 |

字体从 `/public/fonts/` 本地加载，使用 `font-display: swap`。Tailwind 的 `sans`、`serif`、`display`、`mono` 当前均映射到同一套 Journal 字体；不要因类名含 `mono` 引入另一套视觉体系。

中文标题应完整展示；窄屏避免最后一行只剩一个字或标点。摘要可按卡片设计截断，但条目页正文不能截断。长 URL 和引用允许换行，代码与宽表格使用局部横向滚动。

## 容器、间距与圆角

- 内容容器最大 1200px，桌面两侧各预留 32px；600px 以下两侧各预留 18px。首页大版块可通栏。
- 通用卡片 `.archive-box`：24px 内边距、16px 圆角、1px 半透明深蓝边框。
- 卡片外框常用 14–18px 圆角；图片常用 6–9px；输入框常用 10–12px。
- 胶囊按钮、标签与状态徽标使用 `999px` 圆角。圆角胶囊是形状语言，不代表所有徽标都可点击。
- 搜索、档案导航使用 20px 圆角对话框，手机收为 16px；右侧导航抽屉 16px，手机 14px。
- 间距优先复用当前 8、12、16、20、24、32、40px 层级；不要为同类控件随意增加相近值。

## 控件与交互状态

独立按钮、图标操作、筛选、排序和复制控件的可点击高度至少 44px；纯图标操作同时保证至少 44px 宽。正文内链接与非交互徽标不扩大成按钮。卡片内的“阅读档案”装饰提示不单独成为点击目标，整个卡片链接负责触达。

| 状态 | 规则 |
| --- | --- |
| 默认 | 白底、深蓝文字、浅灰边框 |
| 悬停 | 深蓝边框、浅灰蓝背景；文字链接保留下划线反馈 |
| 当前 / 选中 | 深蓝底白字，并同步 `aria-current`、`aria-selected` 或 `aria-pressed` |
| 键盘焦点 | 2px 深蓝轮廓，默认外偏移 5px；不能仅靠悬停表示 |
| 禁用 / 提交中 | 阻止重复动作，并保留可读的状态文字；结束后恢复可操作状态 |
| 成功 | 只有确认完成才显示成功文字，通过 `role="status"` / `aria-live` 通知 |
| 失败 | 保留用户输入，说明下一步，提供重试或可行替代路径 |
| 空状态 | 解释当前没有什么，提供清除筛选、浏览档案或投稿等相关入口 |

搜索框使用容器的 `:focus-within` 轮廓，输入框不叠加第二个轮廓。图标按钮必须有可访问名称；装饰图片使用空 `alt`。显示文字被窄屏隐藏时，保留 `aria-label`。

复制操作必须检查剪贴板结果。自动复制失败时，展示只读且可选中的文本，不得显示“已复制”。系统分享被取消时不报错；不可用时提供复制或邮件路径。

## 搜索与对话框

- 使用原生 `<dialog>`，设置标题关联；打开后聚焦内容，关闭后恢复触发位置。
- 打开任一对话框时锁定背景滚动。切换对话框时，已关闭对话框不得解除新对话框的滚动锁或抢走焦点。
- 搜索支持 `⌘ / Ctrl K` 打开、上下键选择、回车打开、Escape 关闭；中文输入法确认候选时不触发结果导航。
- 搜索结果使用组合框 / 列表框语义，同步高亮、`aria-selected` 与 `aria-activedescendant`。
- 搜索有初始、加载、结果、无匹配、加载失败状态；12 秒超时后提供原地重试，保留关键词。
- 对话框不得超出可视高度；内容在对话框内部滚动。关闭按钮不得被标题挤压。

## 档案与风险状态

| 状态样式 | 视觉表达 |
| --- | --- |
| 草稿 / 已归档 | 浅灰底、次级文字，并展示状态名称 |
| 已提交 / 审核中 | 浅粉底，并展示状态名称 |
| 已发布 | 深蓝底、白字 |
| 已撤回 | 浅红底、删除线，并明确撤回文字 |
| 低风险 | `#e3f5eb` 底 / `#165c40` 字 |
| 中风险 | `#fff3d9` 底 / `#77510d` 字 |
| 高风险 | `#ffe9e7` 底 / `#923d39` 字 |

状态徽标只描述记录的工作流或核验风险，不表示对当事人的定性。发布与可索引规则由内容逻辑控制，不能只用 CSS 隐藏非公开记录。

## 响应式断点

所有宽度均为 CSS viewport px，以下为当前累计生效的 `max-width` 规则。

| 断点 | 核心规则 |
| --- | --- |
| 1200px | 收紧页头间距；动画开关收为 44px 图标，保留可访问名称 |
| 1100px | 隐藏横排主导航，保留菜单抽屉；品牌向左、操作向右 |
| 960px | 首页卡片网格与栏目布局收紧；人物转单列，机构保留双列 |
| 800px | 档案导航、搜索收为 44px 图标；避免 601–800px 页头溢出 |
| 600px | 手机单列内容、横排栏目标题、紧凑页脚与对话框；轮播卡宽 88vw |
| 440px | 隐藏品牌的 Archive Journal 副标，主品牌字号 24px |
| 360px | 页头左右留白 12px、主间隙 6px、操作间隙 4px；保持按钮触达尺寸 |

最低验收宽度 320px。新增内容需检查 320、390、595、601、800、960、1100、1440px；重点检查断点两侧的导航、标题换行、操作区与长文本。不能用全局隐藏横向溢出来掩盖被挤出视口的主要操作。

## 动效与阅读

- 动画开关保存用户选择；未指定时尊重系统 `prefers-reduced-motion`。
- 暂停状态停止自动轮播与话题滚动，滚动导航使用即时定位。
- 轮播在悬停、获得键盘焦点、离开视口或页面不可见时暂停；恢复条件满足后再继续。
- 装饰不能遮挡内容、焦点或点击目标。复制的轮播 / 跑马灯内容不能重复进入键盘导航与辅助技术阅读顺序。
- 页头滚动隐藏时，内部获得键盘焦点必须重新出现。
- 打印时隐藏导航、操作、页脚和纯装饰，保留正文与信源。

## 交付检查

每次 UI 修改至少检查相关断点、键盘焦点、空 / 加载 / 成功 / 失败状态与长文本。涉及异步动作时验证失败后的恢复路径；涉及筛选排序时验证 URL、刷新和浏览器前进后退。截图用于视觉证据，静态类型检查与构建不能代替真实交互验收。

本次截图证据位于 `docs/audit-2026-10-23/`。规范的维护对象是当前源码与可观察行为；后续设计变更应同时更新对应组件规则和本文件。
